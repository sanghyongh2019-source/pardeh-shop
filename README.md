# پرده‌سرا — نمونه‌ی کامل فروشگاه پرده تخصصی

این یک اپلیکیشن Next.js تمام‌پکیج (فرانت‌اند + بک‌اند در یک پروژه) است که
شامل کاتالوگ محصول، سفارشی‌سازی زنده، محاسبه‌ی اقساط، ثبت سفارش، و یک نسخه‌ی
mock از پیش‌نمایش هوشمند پرده روی عکس پنجره است.

## اجرای محلی

```bash
npm install
npm run build
npm start
```

سپس روی `http://localhost:3000` باز می‌شود. یک فایل SQLite در `data/app.db`
به‌صورت خودکار ساخته و با چهار محصول نمونه پر می‌شود (اولین اجرا).

برای توسعه با hot-reload:
```bash
npm run dev
```

## ساختار پروژه

```
src/
  app/
    page.tsx                    صفحه‌ی اصلی + کاتالوگ (از دیتابیس)
    customize/[slug]/page.tsx   صفحه‌ی سفارشی‌سازی هر محصول
    visualize/page.tsx          آپلود عکس پنجره + پیش‌نمایش
    order/[id]/page.tsx         صفحه‌ی تایید سفارش
    api/
      products/                 GET لیست و جزئیات محصولات
      orders/                   POST ثبت سفارش، GET لیست/جزئیات سفارش
      installment/calculate/    POST محاسبه‌ی اقساط
      ai-visualize/             POST تولید پیش‌نمایش (mock)
  components/Customizer.tsx     کامپوننت کلاینت سفارشی‌سازی
  lib/
    db.ts                       اتصال SQLite + ساخت جدول‌ها + seed اولیه
    pricing.ts                  فرمول قیمت‌گذاری بر اساس عرض/نوع دوخت
    installment.ts              فرمول محاسبه‌ی اقساط
    types.ts                    تایپ‌های مشترک
data/app.db                     فایل دیتابیس (به‌صورت خودکار ساخته می‌شود)
public/uploads/                 عکس‌های آپلودشده و نتایج پیش‌نمایش
```

## چه چیزی واقعی است و چه چیزی mock

**واقعی و کاملاً کاربردی:**
- دیتابیس SQLite با جدول‌های محصول، رنگ، سفارش، اقلام سفارش، برنامه‌ی اقساط
- منطق قیمت‌گذاری بر اساس عرض پنجره و نوع دوخت
- منطق محاسبه‌ی اقساط (پیش‌پرداخت، تعداد ماه، نرخ سود، جدول اقساط ماه‌به‌ماه)
- ثبت و بازیابی سفارش‌ها از دیتابیس
- ترکیب‌بندی واقعی تصویر (image compositing) با کتابخانه‌ی sharp — فایل خروجی
  واقعاً روی دیسک ساخته می‌شود، فقط منطق «هوش مصنوعی» آن ساده‌سازی شده.

**mock — باید قبل از استفاده‌ی واقعی جایگزین شود:**

| بخش | وضعیت فعلی | برای نسخه‌ی واقعی چه باید کرد |
|---|---|---|
| پیش‌نمایش هوشمند (`/api/ai-visualize`) | دو پنل رنگی ساده با sharp روی عکس می‌نشیند؛ تشخیص واقعی پنجره وجود ندارد | اتصال به یک مدل image-to-image/inpainting (مثل Stable Diffusion + ControlNet یا Gemini/Imagen API) + یک مرحله‌ی segmentation برای تشخیص خودکار قاب پنجره |
| درگاه اقساط | نرخ سود ثابت نمایشی در `lib/installment.ts`، هیچ پرداخت واقعی انجام نمی‌شود | اتصال به یک درگاه اعتباری/اقساطی بانکی واقعی (نیاز به قرارداد و اعتبارسنجی مشتری) |
| احراز هویت کاربر | وجود ندارد؛ هر کسی می‌تواند سفارش ثبت کند | افزودن ورود/ثبت‌نام (مثلاً NextAuth) قبل از استفاده‌ی تجاری |
| پرداخت کامل (غیر اقساطی) | سفارش فقط با وضعیت «در انتظار پرداخت» ذخیره می‌شود | اتصال به یک درگاه پرداخت آنلاین واقعی (زرین‌پال، آیدی‌پی و مشابه) |

## نکته درباره‌ی دیتابیس

به‌جای Prisma از `better-sqlite3` مستقیم استفاده شده، چون دانلود engine
باینری Prisma در محیط توسعه‌ی این پروژه امکان‌پذیر نبود. اگر می‌خواهید به
Postgres/MySQL مهاجرت کنید، فایل `src/lib/db.ts` تنها جایی است که باید
بازنویسی شود؛ بقیه‌ی کد (API routes) فقط از طریق همین فایل با دیتابیس کار
می‌کند.
